# Sistema de Gerenciamento de Tarefas - TechFlow Solutions

## 📌 Objetivo do Projeto
Desenvolver um sistema básico de gerenciamento de tarefas (CRUD) para uma startup de logística, aplicando práticas de Engenharia de Software e metodologias ágeis (Kanban).

## 🚀 Escopo e Funcionalidades
- **Criar Tarefas**: Cadastro de novas demandas com prioridade.
- **Listar Tarefas**: Visualização do fluxo de trabalho.
- **Atualizar Tarefas**: Alteração de status e responsável.
- **Excluir Tarefas**: Remoção de itens concluídos ou cancelados.

## 🔄 Metodologia Adotada
Utilização da metodologia **Kanban** integrada ao GitHub Projects para controle visual do fluxo de trabalho (*A Fazer*, *Em Progresso*, *Concluído*).

## 🛠️ Tecnologias Utilizadas
- Linguagem: Python
- Testes: PyTest
- CI/CD: GitHub Actions

## 🔀 Gestão de Mudanças (Mudança de Escopo)
- **Alteração**: Adição do campo de "Prioridade Alta/Média/Baixa" e funcionalidade de filtro de tarefas críticas.
- **Justificativa**: Solicitação do cliente para identificar gargalos operacionais na logística em tempo real.

## ⚙️ Como Executar o Projeto
1. Clone o repositório: `git clone <URL_DO_REPOSITORIO>`
2. Execute os testes: `pytest`
